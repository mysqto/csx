# CSX Tabs Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search AI Sessions: list the terminal tabs that run Claude Code, Codex, Gemini CLI or another AI coding agent, and focus one.
- Search Terminal Tabs: list every terminal tab and focus one.
- Search AI Sessions also lists closed sessions. Resume one in the terminal you choose. The extension remembers your choice.
- Works with Ghostty, iTerm2, Terminal, kitty, WezTerm and tmux.
