# `csx tabs` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `csx tabs` (list and focus terminal tabs, with the AI sessions
in them), `csx alfred install`, and an Alfred workflow shipped inside csx.

**Architecture:** Terminal backends and AI-tool agents are pure modules that
build commands and parse output. They reach the OS only through four ports
(`OsaRunner`, `CommandRunner`, `TtyWriter`, `Sleeper`) whose real adapters
live in `src/tabs/os_shim.rs`. An assembly module joins tabs, processes and
agents into rows. The CLI reaches it through a `TabsRunner` port, like the
existing `DaemonRunner` and `McpRunner`.

**Tech Stack:** Rust (existing crates only: serde, serde_json, clap,
thiserror, rusqlite), `osascript -l JavaScript`, `ps`, `kitten`, `wezterm`,
`tmux`, `defaults`.

**Spec:** `docs/superpowers/specs/2026-10-27-csx-tabs-design.md`. Read it
before your task. Where this plan and the spec disagree, the spec wins.

## Global Constraints

- Every real side effect sits behind a trait whose only real implementation
  is in a `*_shim.rs` file. No branching or parsing in shims.
- Coverage stays ≥98% line AND region, measured with:
  `PATH="$HOME/.cargo/bin:$PATH" cargo llvm-cov --all-features --ignore-filename-regex '(_shim\.rs$|/main\.rs$)' --summary-only`
  (rustup's `llvm-tools-preview` is installed, so no `LLVM_COV` variables
  are needed). Each task reports the line and region numbers of the files
  it touched and of the total.
- `cargo fmt`, `cargo clippy --all-targets --all-features -- -D warnings` and
  `cargo test` are green at the end of every task. Every command needs
  `PATH="$HOME/.cargo/bin:$PATH"`.
- No new crates.
- The four-letter company code name from `AGENTS.md` never appears anywhere,
  including fixtures, workflow files and commit messages.
- Commits: author `mysqto <my@mysq.to>` (the repo's configured identity),
  message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  Never use `--no-verify`.
- macOS only at run time: on other platforms `csx tabs` prints an empty list
  and exits 0 (`#[cfg(not(target_os = "macos"))]` only in the shim or the
  runner, not in tested logic).
- Work on branch `feat/tabs` in `/Volumes/Library/iWork/csx`. Parallel tasks
  run in their own git worktree branched from `feat/tabs` and touch only
  their own files.

## Review Focus

1. A tab title or session title with quotes, backslashes, newlines or
   emoji: JXA output must still parse, and Alfred JSON must stay valid. Test
   in Task 3 (Ghostty parse) and Task 7 (Alfred render).
2. A terminal app that is running but refuses scripting (Automation
   permission denied, `osascript` exits 1): one warning row, other apps
   still listed. Test in Task 7 (`list_continues_after_backend_error`).
3. A session whose transcript is huge or has a partial first line after the
   tail cut: enrichment still returns the newest title. Test in Task 2
   (`claude_tail_skips_cut_first_line`).
4. The process for a session exits between listing and focus: `focus`
   exits non-zero with "no longer running", not a panic. Test in Task 7
   (`focus_tty_ref_for_gone_tty_errors`).
5. Two Ghostty tabs with the same title and cwd (one session resumed twice):
   neither gets a `ghostty:` ref by title. Both get `tty:` refs. Test in
   Task 7 (`ghostty_ambiguous_title_falls_back_to_tty_ref`).

```rust
// src/tabs/mod.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "lowercase")]
pub enum AgentStatus { Busy, Idle, Unknown }

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize)]
pub struct AgentInfo {
    pub tool: String,            // stable id, e.g. "claude-code"
    pub pid: u32,
    pub tty: Option<String>,     // "ttys012"
    pub cwd: Option<String>,
    pub session_id: Option<String>,
    pub title: Option<String>,
    pub last_prompt: Option<String>,
    pub status: AgentStatus,     // Default: Unknown
    pub updated_at: Option<i64>, // unix ms
    pub resume_command: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize)]
pub struct Tab {
    pub terminal: String,        // "ghostty" | "iterm2" | "terminal" | "kitty" | "wezterm" | "tmux"
    pub ref_: Option<String>,    // serialized as "ref"
    pub title: String,
    pub cwd: Option<String>,
    pub tty: Option<String>,     // "ttys012", no "/dev/"
    pub window: u32,             // 1-based window order
    pub index: u32,              // 1-based tab order in the window
    pub agent: Option<AgentInfo>,
}
// A row is a Tab. An agent with no tab is a Tab with terminal "" and the
// agent's tty/cwd copied in, ref_ = Some("tty:<tty>") or None.
pub type Row = Tab;

#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize)]
pub struct TabsReport { pub rows: Vec<Row>, pub warnings: Vec<String> }

pub trait OsaRunner { fn run_jxa(&self, script: &str) -> Result<String>; }
pub trait CommandRunner { fn run(&self, program: &str, args: &[&str]) -> Result<String>; }
pub trait TtyWriter { fn write(&self, tty: &str, bytes: &[u8]) -> Result<()>; }
pub trait Sleeper { fn sleep_ms(&self, ms: u64); }

pub struct Ports<'a> {
    pub osa: &'a dyn OsaRunner,
    pub cmd: &'a dyn CommandRunner,
    pub tty: &'a dyn TtyWriter,
    pub sleep: &'a dyn Sleeper,
}

pub trait TerminalBackend {
    fn id(&self) -> &'static str;
    /// Ok(None) when the app is not running.
    fn list(&self, ports: &Ports) -> Result<Option<Vec<Tab>>>;
    /// Focus a tab whose ref this backend issued.
    fn focus(&self, ports: &Ports, tab_ref: &str) -> Result<()>;
    /// Focus the tab that owns `tty`; Ok(false) when this app has no such tab.
    fn focus_tty(&self, ports: &Ports, tty: &str) -> Result<bool>;
}

/// Every lowercase query word appears in the joined searchable fields
/// (title, cwd, terminal, agent tool, agent title, last prompt, session id).
pub fn matches_query(row: &Row, words: &[String]) -> bool;
/// Agent rows first, newest `updated_at` first (None last); then tabs by
/// (terminal, window, index).
pub fn sort_rows(rows: &mut [Row]);

// src/tabs/process.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Process { pub pid: u32, pub ppid: u32, pub pgid: u32, pub tpgid: u32,
                     pub tty: Option<String>, pub elapsed_secs: u64, pub args: String }
impl Process {
    /// basename of argv[0]; for node/bun/deno/python interpreters, the basename
    /// of the first non-flag argument instead (e.g. "gemini" for "node /x/bin/gemini").
    pub fn program(&self) -> String;
    pub fn is_foreground(&self) -> bool; // pgid == tpgid
}
pub const PS_ARGS: &[&str] = &["-axo", "pid=,ppid=,pgid=,tpgid=,tty=,etime=,args="];
pub struct ProcessTable { pub procs: Vec<Process> }
impl ProcessTable {
    pub fn parse(ps_output: &str) -> ProcessTable; // skips malformed lines; tty "??" -> None
    pub fn load(cmd: &dyn CommandRunner) -> Result<ProcessTable>; // runs "ps" PS_ARGS
    pub fn get(&self, pid: u32) -> Option<&Process>;
    pub fn on_tty(&self, tty: &str) -> Vec<&Process>;
}
pub fn parse_etime(s: &str) -> Option<u64>; // "[[dd-]hh:]mm:ss"

// src/db/mod.rs
impl Db { pub fn config_dirs(&self, tool: &str) -> Result<Vec<String>>; } // distinct, non-null, sorted
```

`os_shim.rs` holds four real adapters:

- `RealOsa` runs `/usr/bin/osascript -l JavaScript -e <script>`. A non-zero
  exit is an error that carries stderr.
- `RealCommand` uses `std::process::Command`. A spawn failure or a non-zero
  exit is an error that carries stderr.
- `RealTty` opens `/dev/<tty>` write-only and writes the bytes.
- `RealSleeper` calls `thread::sleep`.

Claude (`tool` `claude-code`, program `claude`):

- Read `<dir>/sessions/<pid>.json` in each `claude_dirs` entry. Use the
  fields `sessionId`, `cwd`, `status`, `name` and `updatedAt`. Status
  `"busy"` is Busy, `"idle"` is Idle, and any other value is Unknown.
- The transcript is `<dir>/projects/<slug>/<sessionId>.jsonl`. The slug is
  the cwd with each character that is not an ASCII letter or digit replaced
  by `-`.
- Read only the last 400_000 bytes. If the read did not start at byte 0,
  drop the first line.
- The title is the last `custom-title.customTitle`. Without one, it is the
  last `ai-title.aiTitle`, and without that, `name`.
- `last_prompt` is the last `last-prompt.lastPrompt`.
- `resume_command` is `cd '<cwd>' && claude --resume <sessionId>`. Escape
  single quotes as `'\''`.
- Without a sessions file, fill in only tool, pid and tty.

Codex (`codex`, program `codex`):

- The candidates are `<codex_home>/sessions/**/rollout-*.jsonl` files
  changed in the last 7 days.
- Read the first line of each: `type` `session_meta`, `payload.id`,
  `payload.cwd`, and the top-level ISO-8601 `timestamp`.
- `ps` does not report a cwd, so match on start time only. Pick the newest
  rollout that starts at or after `now_ms - elapsed_secs*1000 - 5000`.
- The title is the first user `input_text` of a `response_item`, cut to 80
  characters.
- Reuse the ISO-8601 parser in `src/source/codex.rs`. If it is private,
  make it `pub(crate)`.
- `resume_command` is `codex resume <id>`.

### Task 3: Ghostty backend

**Files:** `src/tabs/ghostty.rs`

**Interfaces:**
- Consumes: Task 1 ports and types.
- Produces: `pub struct Ghostty;` implementing `TerminalBackend` (`id` `"ghostty"`),
  plus `pub const MARKER_ATTEMPTS: u32 = 6;` and
  `pub fn osc_title(title: &str) -> Vec<u8>` (`ESC ] 2 ; <title with control chars removed> BEL`).

List: one JXA call. If `Application("Ghostty").running()` is false, print
`null` and the backend returns `Ok(None)`. Otherwise print
`JSON.stringify` of `[{w, t, id, name, cwd}]` over windows (w, 1-based),
tabs (t, 1-based) and each tab's terminals. Parse with serde. `ref_` =
`ghostty:<terminal id>`, `tty` None.

Focus by ref: JXA `focus` on the terminal with that id, then `activate`.
If no terminal has that id, return the error "Ghostty tab not found".

`focus_tty(tty)` uses the marker method from the spec:

1. If Ghostty is not running, return Ok(false).
2. List all titles once (the snapshot).
3. For attempt n from 1 to 6: write `osc_title("csx-<tty>-<n>")` to the
   tty, sleep `50 * n` ms, then run one JXA that returns the id of the
   terminal with that name, or `""`.
4. After 6 misses, return Ok(false).
5. After a hit, focus by id. Then read that terminal's name again. If it
   still equals the marker, write `osc_title(<snapshot title>)`.

### Task 4: iTerm2 and Terminal.app backends

**Files:** `src/tabs/iterm2.rs`, `src/tabs/terminal_app.rs`

**Interfaces:**

- `pub struct ITerm2;` with `id` `"iterm2"` and ref `iterm2:<session id>`.
- `pub struct TerminalApp;` with `id` `"terminal"` and ref
  `terminal:<window id>:<tab index>`.
- Both implement `TerminalBackend` and set `tty` without `/dev/`.

iTerm2 JXA reads `Application("iTerm2")` windows, tabs and sessions. Per
session: `id()`, `name()`, `tty()`, and `variable({named: "session.path"})`
for the cwd. Focus calls `session.select()`, `tab.select()`,
`window.select()` and `activate()`.

Terminal.app JXA reads `Application("Terminal")` windows and tabs. Per tab:
`tty()` and `customTitle()`, with the window `name()` as the fallback title.
There is no cwd. Focus sets `tab.selected = true` and `window.index = 1`,
then calls `activate()`.

If the app is not running, `list` returns `Ok(None)`.

Mark these two backends "built from documentation" in a module doc line,
except Terminal.app, which is checked live in Task 9.

### Task 7: Assembly and rendering

**Files:** `src/tabs/app.rs`, `src/tabs/render.rs`

**Interfaces:**
- Consumes: everything from Tasks 1–6.
- Produces:

```rust
pub struct ListOptions { pub agents_only: bool, pub terminals: Vec<String> /* empty = all */, pub query: Vec<String> }
pub fn backends(kitty_socket: Option<String>) -> Vec<Box<dyn TerminalBackend>>; // ghostty, iterm2, terminal, kitty, wezterm
pub fn list(ports: &Ports, backends: &[Box<dyn TerminalBackend>], agents: &[Box<dyn Agent>],
            ctx: &AgentContext, opts: &ListOptions) -> TabsReport;
pub fn focus(ports: &Ports, backends: &[Box<dyn TerminalBackend>], tab_ref: &str) -> Result<()>;
// render.rs
pub fn render_human(report: &TabsReport) -> String;
pub fn render_json(report: &TabsReport) -> String;   // {"rows":[...],"warnings":[...]}

```

`list` does these steps:

1. Run each selected backend. An `Err` becomes the warning
   `"<id>: <error>"`. Skip `Ok(None)`.
2. Add tmux panes with `tmux::nest`.
3. Load the `ProcessTable` once and run `agent::detect`.
4. Attach each agent to the tab with the same tty.
5. Ghostty tabs have no tty. Strip leading glyphs and spaces (characters
   that are not letters or digits) from each Ghostty tab title. Then find
   the agents whose `title` equals a stripped title. If exactly one agent
   matches, and no other Ghostty tab has the same stripped title, attach
   that agent.
6. Each agent that is still not attached becomes its own row, with `ref_`
   `tty:<tty>` or None.
7. With `agents_only`, keep only rows that have an agent.
8. Filter with `matches_query`, then call `sort_rows`.

`focus` routes by the ref prefix:

- `ghostty:`, `iterm2:`, `terminal:`, `kitty:`, `wezterm:` go to that
  backend's `focus`.
- `tmux:` goes to `tmux::focus`. Then focus the returned client tty as a
  `tty:` ref.
- `tty:<t>`: load a fresh `ProcessTable`. If no process has tty t, return
  the error "the session in /dev/<t> is no longer running". Otherwise call
  `focus_tty` on each backend in order until one returns true. If none
  does, return the error "no supported terminal shows /dev/<t>".
- Any other prefix returns the error "unknown tab ref".

Alfred rows:

- `uid` is the ref, or `pid:<pid>` without one.
- `title` is the agent title, else the tab title.
- `subtitle` joins the non-empty parts with ` · `: `● busy` or `○ idle`,
  tool, terminal, cwd with the home folder shortened to `~`, and the last
  prompt in curly quotes, cut to 80 characters.
- `arg` is the ref. Without a ref, `valid` is false.
- `mods.cmd.arg` is the session id for agent rows, else the cwd.
- If the row has a `resume_command`, `mods.alt` copies it. Otherwise
  there is no `mods.alt`.
- Each warning becomes a row at the top with `valid: false`.
- An empty result becomes one row "No matching tabs" with `valid: false`.
